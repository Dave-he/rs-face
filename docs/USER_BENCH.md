## 跨视频合并实测

run 1 (并联谐振.mp4, --fps 0.3):
- 1440 帧 → 1 个 track (face_id=0), gallery 已写入 tracks.json

run 2 (同一视频, --prior-tracks r1/tracks.json):
- 1440 帧 → 1 个 track (face_id=0 **复用**)
- 画廊余弦距离 < merge_threshold + 0.05 → 自动匹配

结论: 跨视频复用 face_id 工作正常, 同一老师在不同 run 中保持一致标识。
